## Firebase Setup
1. Create a Firebase project.
2. Enable Firestore Database.
3. Generate a service account key.
4. Add FIREBASE_PROJECT_ID, FIREBASE_CLIENT_EMAIL, and FIREBASE_PRIVATE_KEY to Vercel environment variables.

## Deploy
1. Upload to GitHub.
2. Import to Vercel.
3. Add environment variables.
4. Deploy.
